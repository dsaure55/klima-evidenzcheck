# Instagram
## Karussell (Pflicht)
- 4–6 Folien, 1080×1350 px, Stil siehe `grafik.md`.
- Folie 1: Frage/Hook + Reihenzeile. Folie 2–4: je eine Erkenntnis mit einer Zahl/Grafik.
  Vorletzte: „Was die Daten nicht sagen“. Letzte: Fazit + „Ganzer Artikel: Link in Bio“.
- Als eine HTML-Datei `assets/karussell.html` mit einer Section pro Folie.
## Caption
- Emoji als Abschnitts-Header, kurze Bullets. Instagram kennt kein Fett: Kernaussage als eigene Zeile mit Emoji hervorheben.
- Abschnitt „Fazit“ am Ende, dann Quellen in einer Zeile.
- Links sind in Captions nicht klickbar → „Link in Bio“; Bio-Link vor dem Posten auf den Artikel setzen.
- 5–8 Hashtags am Ende.
