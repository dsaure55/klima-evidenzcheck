# WhatsApp-Kanal
- 2–4 Saetze, max. ca. 80 Woerter. Broadcast-Stil, direkt, ohne Fachjargon.
- 1–3 Emojis, eine Kernaussage, ein klarer Satz „Was heisst das?“.
- Fachbegriffe in Alltagssprache erklaeren.
- Link am Ende. Posten erfolgt manuell (keine offizielle API fuer Kanaele).
- Unter dem Link optional eine Kanalzeile: „Auch auf Instagram: https://www.instagram.com/klima_kompass/ · Facebook: https://www.facebook.com/profile.php?id=61595673411252“
- Überschrift immer fett mit WhatsApp-Formatierung (Sternchen): erste Zeile z. B. `*🌡️ Klima Kompass · Wissen:*` bzw. `*🧭 Klima Kompass · Einordnung:*`. Emoji und Reihenzeile stehen innerhalb der Sternchen, direkt danach folgt der Text.
