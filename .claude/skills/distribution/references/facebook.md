# Facebook
- 80–150 Woerter. Erster Satz als Frage oder ueberraschender Befund.
- Emoji-Abschnitte wie Instagram, aber Fliesstext erlaubt; Abschnitt „Fazit“.
- Link direkt im Post (mit UTM). Bild: Folie 1 des Instagram-Karussells wiederverwenden.
- Ton: zugaenglich, fuer lokales/allgemeines Publikum.
- Direkt vor dem Artikel-Link eine kurze Folgen-Zeile (Pflicht seit 20.10.2026, Entscheidung Daniel), z. B. „👉 Folgt Klima Kompass hier auf Facebook – jede Woche Klimazahlen, sauber geprüft.“ Sachlich, ohne Druck, ohne Gewinnspiel-Ton; Wortlaut darf variieren.
- Unter dem Artikel-Link optional eine Kanalzeile: „Klima Kompass auch auf Instagram: https://www.instagram.com/klima_kompass/ · WhatsApp: https://whatsapp.com/channel/0029Vb7dScK5kg74YY4ksf1j“
